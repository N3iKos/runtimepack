Aturan kerja lengkap ada di file global:

`C:\Users\MhsymR\.config\opencode\AGENTS.md`

File ini sengaja hanya berisi rujukan agar tidak ada dua salinan aturan yang bisa berbeda (drift). Jika ada aturan yang perlu diubah, ubah file global tersebut, bukan file ini.

Ringkasan alur wajib yang berlaku di workspace ini:

1. Pahami tujuan, ruang lingkup, dan kriteria selesai.
2. Susun rencana ringkas: tujuan, file/komponen yang diubah, urutan langkah, cara verifikasi, risiko.
3. Ajukan rencana ke pengguna dan tunggu persetujuan eksplisit.
4. Eksekusi bertahap, verifikasi tiap bagian, lalu laporkan bukti hasil.
5. Aktivitas read-only (baca, cari, analisis) boleh langsung tanpa approval.
