RuntimePack — Third-Party Notices
Runtime: renpy-android-7 (official Ren'Py 7.5.3 Android / RAPT runtime)
======================================================================

Scope
-----
This notice bundle covers only the minimal native runtime vendored under:

    runtimes/renpy-7/jni/arm64-v8a/librenpython.so

It does not cover, and no file here vendors, Ren'Py engine Python modules,
the Python 2.7 standard library, game scripts or game assets. Those are
supplied by each game distribution and are packed as immutable game-derived
data; they remain the property of their respective copyright holders.

librenpython.so is a single fat shared library. CPython 2.7.18, SDL2 2.0.20,
pygame_sdl2, the Ren'Py engine C extensions and the bundled third-party
libraries are statically linked into it. The official RAPT runtime has no
separate libpython/libSDL2 shared objects for Android.
