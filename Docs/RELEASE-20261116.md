## Linux usage
Install Rust and the Android/JDK build prerequisites using the documented platform procedure, then run:

```sh
cargo build --locked --release -p runtimepack
./target/release/runtimepack --help
python3 wizard.py
```

The wizard selects `runtimepack` on Linux and `runtimepack.exe` on Windows. `RUNTIMEPACK_EXE` remains an explicit override. No WSL is required. Building Android APKs still requires JDK17+, Android34 SDK/build-tools and Gradle dependency access/cache. Public source lacks license-restricted RGSS native payloads; obtain properly licensed runtime inputs separately rather than bypassing the gate.
